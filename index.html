Collective compute

What if the computer was the room?

This experiment pools the spare computing power in ordinary phones, laptops and tablets. Together they run a single AI model that is divided between the participating devices.

Run the experiment → What happens?
FIELD TEST / 01

One model. Several devices.

There is no model API in the middle. Each browser downloads part of the model, computes its layers locally with WebGPU, then passes intermediate activations to the next device over WebRTC.

Nothing you type should be private. Other devices in the experiment participate in the computation, and activations should be treated as recoverable by participants.
